# Paul Andrei S. Calma — Portfolio

A React + Vite portfolio site.

## Development

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Build

```bash
npm run build
```

Outputs a production build to `dist/`.

## Structure

- `src/main.jsx` — app entry point
- `src/App.jsx` — assembles the page from components
- `src/components/` — Header, Hero, Projects, Skills, Contact, Footer, Cursor
- `src/index.css` — all styling (design tokens + component styles)
